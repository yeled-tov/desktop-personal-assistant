# ✦ שיר — עוזרת AI למחשב

עוזר AI ל-Windows — כמו Gemini בטלפון, אבל למחשב. קוראים לו בקיצור מקשים או בקול, והוא **עושה** דברים: פותח תוכנות, כותב ב-Word, לוחץ ומקליד בכל אפליקציה, מחפש, מתקשר דרך הטלפון המחובר, מתרגם את המסך ועונה על כל שאלה.

## התקנה

1. הורד את `DesktopAssistant-Setup.exe` מעמוד ה-Releases.
2. הפעל. אם Windows SmartScreen מציג "Windows הגן על המחשב" — לחץ **מידע נוסף ← הפעל בכל זאת** (הקובץ לא חתום דיגיטלית).
3. בפתיחה הראשונה בחר ספק AI והדבק מפתח API. הכי קל: **Google Gemini** — מפתח חינמי מ-[aistudio.google.com/apikey](https://aistudio.google.com/apikey).

לא צריך להתקין .NET — הכל כלול בקובץ.

## איך משתמשים

| מה | איך |
|---|---|
| לפתוח את שיר | `Ctrl+Alt+Space` · מקש Copilot · הסמל ליד השעון — נפתח חלון קטן בתחתית המסך |
| לדבר איתה | `Ctrl+Alt+V` או 🎙 |
| הכתבה | `Ctrl+Alt+D` או ✍ — מדברים, והטקסט מוקלד בחלון שבו אתם (Word, וואטסאפ, דפדפן) |
| הקף וחפש | `Ctrl+Alt+S` · לחיצה ארוכה על משטח המגע |
| תרגום כל המסך | `Ctrl+Alt+T` |
| מה היא יודעת לעשות | כפתור **?** בחלון, או לשאול "מה את יודעת לעשות?" |

כל קיצור ניתן לשינוי: ⚙ ← קיצורים ← ✏.

### מה צורך מכסת API ומה לא
- **פקודות מהירות** ("פתחי וורד", "חפשי…", "מה השעה", ווליום, "תזכירי לי בעוד 10 דקות", "תקלידי: …") — מתבצעות במחשב, **בלי AI ובלי מכסה**.
- **הכתבה** — רק תמלול (או אופליין לגמרי).
- **מילת הפעלה** — לעולם לא משתמשת ב-API (רק זיהוי דיבור אופליין).
- משימות מורכבות ושאלות — הסוכן ב-AI (כמה בקשות למשימה רב-שלבית).

### מצב אופליין (אופציונלי)
⚙ ← 🔌 אופליין. מורידים רק אם רוצים — הגודל המדויק מוצג לפני ההורדה:
- **זיהוי דיבור:** 199MB / 583MB / 1.6GB (ivrit.ai — הכי מדויק בעברית).
- **מוח מקומי (Qwen3-VL, מבין גם את המסך):** 1.6GB (למחשבים עם 8GB זיכרון) / 3GB (16GB זיכרון).

אחרי ההורדה הכל עובד בלי אינטרנט: דיבור, הכתבה, מילת הפעלה, תשובות, הפעלת המחשב, ראיית המסך ותרגום. במצב **אוטומטי** שיר משתמשת בענן, ועוברת למוח המקומי כשאין אינטרנט או שהמכסה נגמרה.
במחשב בלי כרטיס מסך חזק המוח המקומי איטי יותר מהענן (הבקשה הראשונה טוענת אותו לזיכרון, כחצי דקה).

### מילת הפעלה ("היי שיר")
כבויה כברירת מחדל. צריך את זיהוי הדיבור האופליין. המיקרופון מנותח במחשב בלבד; בשקט זה כמעט לא צורך מעבד, ורק משפטים קצרים נבדקים במנוע המקומי. ברירת מחדל: מושהית כשהמחשב על סוללה. את השם ואת המילה משנים בהגדרות.

## בטיחות
פעולות רגישות — שיחת טלפון, הרצת פקודת מערכת, דריסת קובץ, לחיצה על "שלח/קנה/מחק" — מוצגות לאישור לפני ביצוע (ניתן לכבות בהגדרות).
העוזר שולח צילום מסך ל-AI רק כשהוא צריך לראות את המסך (שאלה על המסך, הקף וחפש, תרגום, או כשהוא מפעיל אפליקציה שאין לה רכיבים נגישים).

## בעיות?
- **לא נפתח?** בגרסה הקודמת הייתה שגיאה ב-`app.manifest` (`PerMonitorV2` בתוך `<dpiAware>`) ש-Windows 11 24H2 הורג בגללה את התהליך עוד לפני שהקוד רץ. תוקן.
- לוגים: סמל המגש ← "פתח את תיקיית הלוגים" (`%LOCALAPPDATA%\DesktopAssistant\logs`).
- קיצור תפוס על ידי תוכנה אחרת → מופיעה הודעה; בחר קיצור אחר בהגדרות.
- העוזר לא יכול להקליד בחלונות שרצים כמנהל (Windows חוסם זאת) אלא אם גם הוא רץ כמנהל.

## פיתוח
```powershell
# דרישות: .NET 10 SDK, NSIS (להתקנה)
.\scripts\build-release.ps1 -Version 2.0.0   # בונה, מריץ בדיקת הפעלה אמיתית (--smoke-test), ויוצר מתקין
```
מבנה הקוד:
- `AI/` — ספקים (Gemini, OpenAI-compatible, Anthropic) מאחורי ממשק אחד, כולל קריאת כלים ותמונות.
- `Agent/` — לולאת הסוכן (חשיבה ← פעולה ← בדיקה) ו-34 הכלים שלו.
- `Desktop/` — הקלדה/עכבר (SendInput), חלונות, UI Automation, Word דרך COM, צילום מסך, פתיחת אפליקציות.
- `Input/` — קיצורי מקשים גלובליים, זיהוי לחיצה ארוכה (mouse hook בת'רד נפרד).
- `Overlay/` — הקף וחפש ותרגום מסך (חלון קפוא לכל מסך, מדויק בפיקסלים בכל DPI).
- `Voice/` — הקלטת מיקרופון (waveIn) והקראה (קולות Windows).
- `UI/` — חלון העוזר, הגדרות, ברוכים הבאים, מגש, התראות.

ה-CI (`.github/workflows/windows-build.yml`) בונה על Windows אמיתי, **מפעיל את ה-EXE בפועל** במצב בדיקה, ורק אם הוא עלה בהצלחה — מפרסם Release.
